Privacidade e dados

  • Nenhum dado é enviado a servidores próprios. As análises ficam no LocalStorage deste navegador.
  • Quando a API real está configurada, a lista de medicamentos é enviada ao provedor do modelo escolhido. Não envie dados identificáveis de pacientes reais.
  • Use apenas dados fictícios para demonstração.
  • Você pode apagar todos os registros a qualquer momento na aba “Histórico”.
